# Scripts

This directory contains runnable public scripts for SPRINT.

## Files

- `generate_example_data.py`: generate toy SNP, PRS, and label CSV files in the expected input format.
- `train_sprint.py`: train and evaluate SPRINT using a YAML configuration file.
- `plot_summary_results.py`: plot summary-level public results from CSV files in `results/`.
- `smoke_test.py`: small dependency and model test using randomly generated arrays.

Individual-level genotype, phenotype, PRS, and prediction files are not included in this repository.
